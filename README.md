# 赛博大肥鱼 · 沉浸式电子木鱼禅堂

一敲一念，心静福生。单文件零依赖的沉浸式古刹赛博禅堂网页，内置 640p 高清大肥鱼敲头动图与正宗「哦鲸鲸」原声。

## 在线体验
- **Cloudflare 全球加速**：https://cyber-dafeiyu.lens-frontier.workers.dev
- **GitHub Pages**：https://mattheliu.github.io/cyber-dafeiyu/

## 特性
- **真实古刹禅堂空间**：月色圆窗、朱漆殿柱、鎏金匾额、紫檀供案、锦缎蒲团、摇曳长明酥油灯、可互动青铜三足香炉（插三炷沉香 + 袅袅青烟 + 15 分钟静心倒计时）。
- **多尊者角色与原生音效联动**：
  - 🐳 **大肥鱼娘**：640p 高清 17 帧逐帧敲头 + 正宗「哦鲸鲸」原声
  - 🪵 **古刹紫檀木鱼**：清脆木鱼 + 大殿微混响
  - 🐱 **赛博招财猫**：招财金铃 + 陶瓷轻敲声
  - 💻 **机房绿乖乖**：机房双音绿灯脆响
  - 🖼️ **用户自定义**：支持上传/拖拽任意图片与自定义 MP3/WAV 音效（本地持久化，刷新不丢），同时支持自定义匾额名称与飘字词条。
- **沉浸式仪式感（无挂机）**：支持 `Space` 静心敲击、5% 顿悟暴击、`夜雨听禅 / 古寺风铃 / 颂钵低鸣` 纯本地合成白噪音、每日赛博求签、放飞许愿灯、`H` 键进入纯粹禅定模式，以及导出竖版「赛博功德帖」海报。

## 本地运行
直接双击打开 `index.html` 即可离线体验。
